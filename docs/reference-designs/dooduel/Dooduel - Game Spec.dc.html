01

Concept & objective

Dooduel is an online, real-time pictionary. Each turn, one player is the drawer and is given a secret word to sketch on a shared canvas. Everyone else are guessers who race to type the word into chat. The faster you guess, the more points you score; the more people who guess your drawing (and the faster), the more the drawer scores.

Turns rotate so everyone draws. After a set number of rounds, the player with the most total points wins. It's light, fast, and chaotic — equal parts skill and comedy. No download, no account: pick a name and play.

Notable states & overlays

  • ›Lobby (private): player list, host's settings panel, copy-able invite link, "Start game" gated to host.
  • ›Word-pick overlay: shown only to the drawer at the start of their turn (3 choices + a countdown to auto-pick).
  • ›"Waiting for drawer": guessers see a held state while the drawer chooses.
  • ›Turn-end reveal: the word, who got it, and the points each player gained this turn.
04

Roles: drawer vs guesser

The drawer
One per turn
  • ›Picks 1 of 3 offered words
  • ›Sees the full word at top
  • ›Draws with brush, colors, fill, eraser, undo, clear
  • ›May not type letters / spell the word
  • ›Can't chat with active guessers mid-turn
The guessers
Everyone else
  • ›Watch strokes appear live
  • ›Type unlimited guesses in chat
  • ›See letter-count slots + revealed hints
  • ›On a correct guess: locked in, word hidden from them no more
  • ›After guessing, chat moves to a spoiler-safe stream
05

Scoring

Both sides are rewarded, so drawing well and guessing fast both matter. Exact constants are tunable; the model below is representative of skribbl's behavior.

Guessers

Points scale with how much time is left when you guess and your order — the first correct guess scores highest, each later guesser a little less.

Drawer

Earns based on how many players guessed correctly and how quickly — a clear, fast-read drawing pays off.

Edge cases

  • ›Nobody guesses: no points for anyone that turn — guessers and drawer.
  • ›Drawer leaves mid-turn: turn is voided, no points awarded.
  • ›Wrong guesses: no penalty — but they're visible to others and can accidentally help.
06

Words & hints

Partial in MVP

Word selection

At the start of a turn the drawer is offered 3 random words and picks one. If they dawdle, one is auto-chosen when the pick-timer expires.

Hint reveal

Guessers see one underscore per letter (spaces shown). As the clock ticks down, a configurable number of letters flip open:

_ A _ _ _ _ _ 7 letters · 1 hint revealed

Word modes (advanced)

  • ›Normal — a single word from the pool.
  • ›Hidden — the letter count isn't shown.
  • ›Combination — two pooled words joined (e.g. "apple + tree").

Languages: original ships ~26. Custom word lists let hosts theme a room (movies, inside jokes, class vocab).

Drawing tools

A deliberately small, approachable toolset — the point is communication, not fine art.

Fill / bucket

Eraser
paint back to canvas white
Undo · Clear
step back, or wipe the canvas

Input: mouse or touch. Desktop keyboard shortcuts speed up tool/color switching. Only the drawer can draw; strokes broadcast to everyone in real time.

08

Chat & guessing

In MVP

Guessing happens entirely in one chat box — it doubles as the game's social heartbeat.

  • ›Type a word; an exact match marks you correct and is hidden from others so it isn't spoiled.
  • ›Close-guess nudge: a near-miss gets a private "so close!" hint.
  • ›Once correct, you (and the drawer) drop into a spoiler-safe side channel invisible to players still guessing.
  • ›System lines mark turn start/end, who guessed, and the final word reveal.

MVP scope for the prototype

Your ask: a simple, full interactive prototype — multiple players, sketching, guessing. Here's the line I'd draw so it feels like a real, complete game while staying buildable in a single file.

✓In the prototype
  • ›Home: enter name + pick avatar, one click to play
  • ›Working canvas: brush, fill/bucket, sizes, color palette, eraser, undo, clear
  • ›Timer + word with letter-slot hints revealing over time
  • ›Chat with real guess detection → correct guess locks & scores
  • ›Dev-only "playing as" switcher — multiplayer is mocked; one human seat-hops between every player instead of bots
  • ›Turn rotation, scoring, turn-end reveal, final podium
  • ›Live scoreboard + drawer/guesser role states
→Deferred (full game)
  • ›Real networked multiplayer + rooms + invite links
  • ›Public matchmaking
  • ›Word modes (hidden / combination), custom word-list editor
  • ›Full color set (20+), languages beyond English
  • ›Votekick, like/dislike, avatar editor
  • ›Accounts, profiles, persistent stats
13

Key decisions

These forks are settled — kept here so future edits stay consistent with what's actually built, not with earlier options that were considered and dropped.

  1. ✓
    1 · How do we fake "multiple players" in one file?
    Decided

    No bots. A dev-only "playing as" switcher lets one human seat-hop between every player — become the drawer to pick & sketch, jump to a guesser seat to answer, jump again to answer as someone else. Canvas, chat, scores and timers are all global state that keeps running no matter who's currently "in the seat."

  2. ✓
    2 · How does the game keep pace with nobody "home" by default?
    Decided

    Each new turn auto-jumps the switcher to whoever is drawing next, so picking + drawing never stalls. Guessing is opt-in — manually switch to a guesser seat to answer for them. The same human will always know the secret word once they've seen it as drawer; that's an accepted quirk of solo, perspective-swapped play, not a bug.

  3. ✓
    3 · Visual direction
    Decided

    Full character pass, not a Protokit-clean base: locked a single purple accent (light + dark), swapped to a hand-drawn type pairing (Caveat display + Shantell Sans UI), ink-colored sketchy borders with wobbly asymmetric corners, chunky 3D-press buttons, confetti + a podium finale, and emoji-forward copy throughout.

  4. ✓
    4 · Layout target
    Decided

    Desktop-first, fixed-width layout: canvas center, scoreboard left, chat right. No responsive/mobile pass in this prototype.
