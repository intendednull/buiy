# Glossary

Quick reference for sickle-specific terminology used in this corpus. The terms are clustered by what they describe.

## Authoring DSL

- **`UiBuilder<E>`** — the central fluent-API anchor. A typed wrapper over a `Commands` reference + an entity id `E` (typically `Entity`, or `UiRoot` at the top of the tree). Every widget-spawn extension method is implemented on `UiBuilder<Entity>`.
- **`UiRoot`** — marker type used as the "parent" for the top-of-tree `ui_builder(UiRoot)` call. Not an entity; a phantom-type placeholder.
- **`UiContextRoot`** — utility type for locating safe root nodes when spawning into an existing UI tree.
- **`UiBuilderExt`** — base extension trait on `Commands` that adds `.ui_builder(E)`.
- **`UiBuilderGetId`** — trait letting any type that exposes its entity id gain the full `UiBuilder` method surface. The composition pattern that powers typed sub-builders (e.g. `slider.bar()` returns a `UiBuilder<SliderBarEntity>`).
- **`Ui<Name>Ext`** — naming convention for the ~30 widget-spawn extension traits (e.g. `UiButtonExt`, `UiColumnExt`, `UiCheckboxExt`). Each widget module exports one.
- **`Set<Property>Ext`** — naming convention for the ~150 style-setter extension traits (e.g. `SetWidthExt`, `SetBackgroundColorExt`, `SetFlexDirectionExt`). Generated by the `StyleCommands` derive macro.

## Interaction state machine

- **`FluxInteraction`** — sickle's refinement of `bevy_ui::Interaction`. Enum with variants `None`, `PointerEnter`, `PointerLeave`, `Pressed`, `Released`, `PressCanceled`, `Disabled`. Helper predicates `is_pressed()`, `is_released()`, `is_canceled()`, `is_disabled()`.
- **`FluxInteractionStopwatch`** — per-entity clock recording how long the entity has been in its current `FluxInteraction` variant. Drives time-based style animation.
- **`TrackedInteraction`** — wraps previous + current `FluxInteraction` so widget systems detect transitions without retaining per-system state.
- **`PrevInteraction`** — companion enum for `TrackedInteraction`.

## Theming

- **`Theme<C>`** — typed theme component for widget type `C`. Carries a vector of `PseudoTheme<C>` entries.
- **`PseudoTheme<C>`** — one theme variant keyed by a list of `PseudoState`s. Holds a `DynamicStyleBuilder` closure that the engine invokes when the variant becomes active.
- **`ThemeData`** — runtime theme data the user populates per app: color palette (`theme_colors`), spacing scale (`theme_spacing`), typography (`typography`), icons (`icons`).
- **`ThemeRegistry`** — runtime resource tracking every registered theme by widget type.
- **`ThemePlugin`** — base theming infrastructure plugin (registered by `SickleUiPlugin`).
- **`ComponentThemePlugin<C>`** — per-widget-type plugin that registers `Theme<C>` with the `ThemeRegistry`. User adds this for custom widgets: `app.add_plugins(ComponentThemePlugin::<MyWidget>::default())`.
- **`DefaultTheme`** — user-implementable trait declaring a widget's baseline theme. Often combined with `#[derive(DefaultTheme)]`.
- **`UiContext`** — trait letting a widget expose named sub-entity slots (e.g. `slider.get("bar")` returns the bar entity). Themes target sub-entities by name.

## Dynamic styling

- **`DynamicStyle`** — runtime data structure attached to entities whose visual properties should respond to interaction state and pseudo-states. Carries a vector of `DynamicStyleAttribute`s.
- **`DynamicStyleAttribute`** — one styled property tagged as static, interactive, or animated. The animation timing comes from `DynamicStyleStopwatch`.
- **`DynamicStyleBuilder`** — builder type for constructing `DynamicStyle` programmatically from theme closures.
- **`ContextStyleAttribute`** — `DynamicStyleAttribute` targeting a named sub-entity via `UiContext` rather than the current entity.
- **`DynamicStyleStopwatch`** — per-entity clock for animated attributes.
- **`DynamicStyleEnterState`** / **`DynamicStylePostUpdate`** — Bevy system-set markers for sickle's style-resolution passes.
- **`StyleBuilder`** — the procedural builder that theme closures populate; produces a `DynamicStyle` when resolved.
- **`UiStyle`** / **`UiStyleExt`** — style-application command + extension. `.style().background_color(...)` returns a `UiStyle`-builder.
- **`UiStyleUnchecked`** / **`UiStyleUncheckedExt`** — bypass for `LockedStyleAttributes`. Forces an override even when a property is locked.
- **`LockedStyleAttributes`** — component letting a widget protect chosen visual properties against user override.
- **`TrackedStyleState`** — enum marking the lifecycle stage of a tracked-style attribute.
- **`LogicalEq`** — comparison trait for style attributes (semantic equality, not bitwise).

## Pseudo-state plumbing

- **`PseudoState`** — enum of pseudo-class equivalents: `Hover`, `Pressed`, `Focused`, `Checked`, `Open`, `Selected`, `Disabled`, plus structural variants (`OddChild`, `FirstChild`, `LastChild`), folder-state variants, flex-direction variants. Drives `PseudoTheme<C>` lookup.
- **`PseudoStates`** — component carrying the set of currently-active `PseudoState`s on an entity.
- **`AutoPseudoStatePlugin`** — registers the systems that propagate pseudo-state changes from `FluxInteraction`, visibility, hierarchy, and flex direction.
- **`HierarchyToPseudoState`** — system mapping hierarchy position (first / last / odd child) to `PseudoState` entries.
- **`VisibilityToPseudoState`** — system mapping visibility changes to `PseudoState` entries.
- **`FlexDirectionToPseudoState`** — system mapping flex direction to `PseudoState` entries.

## Companion crates

- **`sickle_ui_scaffold`** — separate crate carrying the theming engine + builder + style-engine + flux-interaction. The substrate `sickle_ui` (catalog) consumes. Third-party widget authors can depend on `sickle_ui_scaffold` directly without pulling the catalog.
- **`sickle_macros`** — proc-macro crate exporting the four derives: `DefaultTheme`, `EventHandler`, `StyleCommands`, `UiContext`.
- **`sickle_math`** — small math helpers (curves, easing) used by `DynamicStyle`'s animated attributes.

## Salvaged-into-cobweb

- **`cob_sickle_math`** / **`cob_sickle_macros`** / **`cob_sickle_ui_scaffold`** — v0.8.0 vendored copies of the sickle scaffold layer in `bevy_cobweb_ui`'s `crates/` directory. The lineage continuation of sickle's design-DNA into a different namespace and a later Bevy version (0.17).

## Surrounding ecosystem terms

- **APG** — WAI-ARIA Authoring Practices Guide. Defines the keyboard contracts and ARIA role/state/property patterns for every standard widget. sickle implements none of these.
- **BSN** — Bevy Scene Notation (PR #20158, still draft). The proposed data-format authoring scheme that sickle's extension-trait DSL is structurally hostile to. See [`../bevy-ui/lessons.md`](../bevy-ui/lessons.md) for BSN's current status.
- **RequiredComponents** — Bevy 0.15 mechanism (PR #14791) where `#[require(Companion)]` on a Component derive auto-inserts companion components. The change that sickle's maintainer named as the trigger for declaring the project obsolete.
