# Glossary

Quick-reference of Slate / UMG terminology. Each entry is one sentence + a pointer to the file that goes deeper. Keep this file flat — alphabetical within sections.

## Stacks and layers

- **Slate** — Unreal's declarative C++ retained-mode UI framework; the load-bearing programmer-facing UI runtime; ~2010 origin, stable since UE4 launch in 2014. See [`slate-architecture.md`](slate-architecture.md).
- **UMG** — Unreal Motion Graphics; the designer-friendly Blueprint-driven asset-based UI layer that wraps Slate; introduced in **UE 4.5 (November 2014)**. See [`umg-architecture.md`](umg-architecture.md).
- **CommonUI** — Epic plugin extracted from Fortnite (UE 4.27+); cross-platform input routing, controller-icon swap, activatable widget stack, action bar. See [`ecosystem-and-comparisons.md`](ecosystem-and-comparisons.md).
- **MVVM plugin** — Model-View-ViewModel plugin (UE 5.1+); change-driven data binding replacement for per-frame "Bind Function" attributes.

## Prefixes

- **`S`** — Slate widget class prefix. `SButton`, `STextBlock`, `SImage`, `SOverlay`. C++ retained-mode widget.
- **`U`** — UObject prefix (general Unreal). For UMG widgets specifically: `UButton`, `UTextBlock`. `U`-widgets *wrap* `S`-widgets.
- **`F`** — value-struct prefix. `FSlateBrush`, `FSlateFontInfo`, `FArguments`, `FText`.
- **`T`** — template prefix. `TSharedRef<SWidget>`, `TAttribute<T>`, `TSharedPtr<T>`.
- **`I`** — interface prefix. `IAccessibleWidget`, `ITextInputMethodContext`.

## Core Slate classes

- **`SWidget`** — abstract base for all Slate widgets; defines paint, layout, input, accessibility virtuals.
- **`SLeafWidget`** — Slate widget with no children (`STextBlock`, `SImage`, `SSpacer`).
- **`SCompoundWidget`** — Slate widget composed of other widgets via a `ChildSlot`; the most-extended base.
- **`SPanel`** — Slate base for multi-child layout containers (`SHorizontalBox`, `SVerticalBox`, `SOverlay`, etc.).
- **`FSlateApplication`** — global Slate singleton; owns focus, drag-drop, modal stack, tooltips, renderer plumbing.
- **`FSlateRenderer`** / **`FSlateRHIRenderer`** — Slate's renderer; translates draw elements into RHI commands.

## Slate macros

- **`SNew(WidgetType)`** — primary widget construction macro; expands to `MakeShared<WidgetType>()` + an `FArguments` proxy.
- **`SAssignNew(MemberPtr, WidgetType)`** — like `SNew` but assigns the constructed widget to a member `TSharedPtr`.
- **`SLATE_BEGIN_ARGS(ClassName)` / `SLATE_END_ARGS()`** — define a nested `FArguments` struct on the widget class.
- **`SLATE_ARGUMENT(Type, Name)`** — declare a plain construction-time argument inside `FArguments`.
- **`SLATE_ATTRIBUTE(Type, Name)`** — declare a `TAttribute<T>`-bindable argument (literal or lambda).
- **`SLATE_EVENT(DelegateType, Name)`** — declare a delegate callback argument.
- **`SLATE_NAMED_SLOT(Args, Name)`** — declare a named child slot fillable via `.Name() [ child ]`.
- **`BEGIN_SLATE_FUNCTION_BUILD_OPTIMIZATION` / `END_SLATE_FUNCTION_BUILD_OPTIMIZATION`** — bracket `Construct` bodies to disable compiler optimization on the function (workaround for MSVC compile times).

## Slate value types

- **`FArguments`** — nested struct generated by `SLATE_BEGIN_ARGS`; holds construction-time argument values.
- **`TAttribute<T>`** — bindable property; either a literal value or a lambda re-evaluated per frame.
- **`TSharedRef<T>` / `TSharedPtr<T>`** — Unreal's shared-pointer types; Slate widgets are managed by these.
- **`FText`** — localizable string (LOCTEXT/NSLOCTEXT macros); the only type allowed for user-visible UI strings.
- **`FSlateBrush`** — draw-this-element descriptor; variants include `FSlateBoxBrush` (9-slice), `FSlateImageBrush`, `FSlateRoundedBoxBrush`, `FSlateColorBrush`, `FSlateMaterialBrush`. See [`layout-and-styling.md`](layout-and-styling.md).
- **`FSlateFontInfo`** — font handle; family, typeface, size, outline, fallback. See [`text-rendering.md`](text-rendering.md).
- **`FSlateStyleSet`** — named collection of brushes/fonts/colors/styles; registered globally.
- **`FSlateStyleRegistry`** — global registry of style sets; `FindSlateStyle("Name")` retrieves.
- **`FAppStyle`** (UE5) / **`FEditorStyle`** (UE4-era alias) — the editor's primary style set.
- **`FSlateDrawElement`** — single drawable primitive (rect, text run, line, spline, custom mesh); batched by `FSlateRenderer`.

## UMG classes

- **`UWidget`** — UObject base for all UMG widgets; defines `TakeWidget()` to construct backing Slate widget.
- **`UPanelWidget`** — base for multi-child layout panels.
- **`UPanelSlot`** — base for slot configuration objects; per-panel subclass (`UCanvasPanelSlot`, `UHorizontalBoxSlot`, etc.).
- **`UUserWidget`** — base class for Widget Blueprints; subclassed via WBP assets.
- **`UCanvasPanel`** — free-positioned anchored layout (default WBP root).
- **`UHorizontalBox`** / **`UVerticalBox`** — linear layouts.
- **`UGridPanel`** / **`UUniformGridPanel`** — grid layouts.
- **`UScrollBox`** / **`UWrapBox`** / **`UOverlay`** — other UMG panels.
- **`UButton`**, **`UCheckBox`**, **`USlider`**, **`UProgressBar`**, **`UComboBoxString`**, **`UTextBlock`**, **`URichTextBlock`**, **`UEditableTextBox`**, **`UMultiLineEditableTextBox`**, **`UImage`** — common UMG widgets; each wraps an `S`-prefixed Slate widget.
- **`UWidgetAnimation`** — UMG animation track; multiple per WBP, played from Blueprint.
- **`UMVVMViewModelBase`** — MVVM plugin's base view-model class.

## UMG concepts

- **Widget Blueprint** (**WBP**) — `.uasset` asset that defines a `UUserWidget` subclass; opened in the Widget Blueprint Editor. Conventionally prefixed `WBP_`.
- **Widget Blueprint Editor** — UMG visual editor; three tabs: **Designer**, **Graph**, **Animation**.
- **Designer tab** — visual canvas + Palette + Hierarchy + Details panels for the WBP layout.
- **Graph tab** — Blueprint visual-scripting graph for the WBP's event handlers and logic.
- **Animation tab** — keyframe animation tracks for the WBP.
- **Palette** — toolbox of available widget classes (drag into Hierarchy / Designer canvas).
- **Hierarchy** — tree-view of all widgets in the WBP.
- **Details panel** — property editor for the selected widget; exposes reflected `UPROPERTY` fields plus the slot-config struct.
- **`bIsVariable`** — per-widget toggle exposing the widget as a Blueprint variable for the Graph tab.
- **Bound attribute / "Bind Function"** — UMG's per-frame Blueprint-callable binding; "inefficient" per Epic's optimization guidelines.
- **TakeWidget** — `UWidget::TakeWidget()` method that constructs and returns the backing `SWidget`.
- **AddToViewport** — `UUserWidget::AddToViewport()` method that inserts the WBP into the game viewport.

## Layout / box-model concepts

- **`ChildSlot`** — the single slot owned by `SCompoundWidget`; filled in `Construct`.
- **`Slot` (chained `+ Container::Slot()`)** — Slate's per-child slot configuration in a multi-child container.
- **`FillWidth(weight)` / `FillHeight(weight)`** — proportional-share sizing (flex-grow-like).
- **`AutoWidth()` / `AutoHeight()`** — sized to child's desired size only.
- **`HAlign(EHorizontalAlignment)` / `VAlign(EVerticalAlignment)`** — alignment within the slot's allocated rect.
- **Anchors** (`FAnchors`) — `UCanvasPanel`/`SConstraintCanvas` per-child anchor rect.
- **`SInvalidationPanel`** — subtree-cache wrapper; re-paints lazily.

## Accessibility concepts

- **`AccessibleBehavior`** — per-widget enum: `NotAccessible` / `Auto` / `Summary` / `Custom`.
- **`AccessibleText`** — per-widget literal accessible name (when `AccessibleBehavior == Custom`).
- **`CanChildrenBeAccessible`** — subtree gate for accessibility tree publication.
- **`IAccessibleWidget`** — Slate interface implemented by widgets that participate in the accessibility tree.

## Reflection / Blueprint

- **`UObject`** — Unreal's reflected-object base; all UMG widgets are UObjects.
- **`UPROPERTY`** — macro that exposes a field to reflection, Blueprint, serialization, undo/redo.
- **`UFUNCTION`** — macro that exposes a function to reflection, Blueprint, etc.
- **Blueprint VM** — the bytecode VM Unreal Blueprints run on; slower than C++ but reflection-friendly.
