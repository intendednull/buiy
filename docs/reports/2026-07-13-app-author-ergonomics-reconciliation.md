## Deferred / routed — rationale

- **7a-lint (DEFERRED)** — surfacing the §4.1c required-component suppression at compile/lint time is XL/high-uncertainty: it lives inside upstream Bevy's `bsn!` proc-macro Buiy does not own, there is no in-repo dylint/clippy-driver infra, and a runtime debug-assert cannot substitute (it cannot distinguish a legitimate partial-patch from an accidental require-suppression — the signal is author-time-only). Interim mitigation landed: a scene-fn for every styleable widget (all 14) + a round-trip regression test pinning the behavior. Revisit if Buiy adopts a lint toolchain or forks `bsn!`.

- **1d-deep-web (ROUTED → #143)** — the report's 'a correct tree reaches zero AT on web' worry is obsolete for outbound a11y (`WebA11ySinkPlugin` ships the ARIA sink). The residual (inbound web AT still inert; best-effort clipboard/IME degrade silently; no web-a11y CI conformance guard) is owned by the active web-firstclass campaign (draft PR #144). Not duplicated here.
