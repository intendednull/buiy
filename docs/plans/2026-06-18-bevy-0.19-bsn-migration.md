# Bevy 0.19-rc migration + BSN integration — plan

**Date:** 2026-06-18
**Status:** active
**Spec:** [docs/specs/2026-06-18-buiy-bsn-integration-design.md](../specs/2026-06-18-buiy-bsn-integration-design.md)

How Buiy gets from Bevy 0.18.1 to Bevy 0.19.0-rc.3 with working `bsn!` authoring. Strictly dependency-ordered: deps → compile → headless → GPU → `buiy_bsn` → example → docs. Each phase has a gate; do not advance until it is green. Review (fresh-context agent) after each phase per the project's review-gated pipeline.

Research substrate (file:line sites, full hit-lists): [docs/reports/2026-06-18-bevy-0.19-bsn-migration-research.md](../reports/2026-06-18-bevy-0.19-bsn-migration-research.md).

## Conventions

- TDD where a behavior changes (BSN round-trip, widget `#[require]`, any logic touched). The migration proper is mostly mechanical API conformance — driven by the compiler, not new tests; existing tests are the regression net.
- Two-lane verification stays load-bearing: the **headless gate** (CI, no adapter) must stay green independently of the **GPU `--ignored` lane** (real adapter).
- `Cargo.lock` is **gitignored** (not committed — this is an app-style workspace), so there is no tracked lock delta to review. Regenerate the on-disk lock via a build and verify single resolved versions with `cargo tree -i`; re-run `cargo deny check` before finalizing.
- `bevy_scene` reaches every workspace member via the **additive** workspace `bevy` feature list (resolver-2 union) — no per-crate/per-example feature edit is needed; the absence of `bevy_scene` in member manifests is intentional.

## Phase 1 — Compile green

Drive `cargo check --workspace` to zero errors, in dependency order (resolution errors mask downstream; fix imports first).

- T1.0 **Spike first (R1 + Q1, before the full rewrite).** (a) Grep `crates/buiy_core/src/render/` for raw `wgpu::` / `render_resource::` descriptor literals vs. Bevy-wrapper usage, to size T1.4 (which wgpu field changes Buiy must make vs. Bevy absorbs). (b) Pin the render-graph-rewrite shape against vendored `bevy_core_pipeline` 0.19 `core_2d/mod.rs:84-90` + `main_transparent_pass_2d`: confirm the `Core2dSystems::EarlyPostProcess` slot, the `ViewQuery`/`RenderContext`-SystemParam signature, and whether Buiy's passes become *separate* systems or *one* straight-line system. (The spike settled this: **one** `buiy_pass` system running all passes straight-line — they must share a single `RenderContext` command encoder for the cross-pass `LoadOp::Load` composite ordering; separate systems would each get their own encoder/command-buffer and break it.) Output: a short note pinning the model before T1.3 starts. This is the residual research-report Q2 unknown — settle it here, not "during implementation."
- T1.1 **Import relocations.** `bevy::render::render_graph` (removed), `bevy::core_pipeline::core_2d::graph` (relocated), `bevy::shader::Shader` / `load_internal_asset!`, any `bevy_reflect` module moves (`Struct`/`DynamicStruct`/… into submodules). Sites: `render/node.rs:22,26`, `render/mod.rs:196-227`, `render/pipeline.rs`.
- T1.2 **ECS renames.** `Replace`→`Discard` lifecycle (6 observer sites in `layout/mod.rs` + `layout/systems.rs`); `system_type()`; `Ref::clone` semantic (use `.into_inner().clone()` where the inner `T` was wanted); `Command` `Out` assoc type if any custom commands; non-send accessor renames; `Mutability = Mutable` bounds on generic resource code. Audit `#[reflect(Resource)]` ×5 for the `ReflectResource`→`ReflectComponent` read-back semantic.
- T1.3 **Render-graph → system rewrite** (spec § 3; the largest unit, **R1**). Convert `BuiyNode: ViewNode` into **one** `buiy_pass` system added to the `Core2d` schedule, ordered in **`Core2dSystems::EarlyPostProcess`** (the verified successor to the removed `StartMainPassPostProcessing→Buiy→Tonemapping` slot — `core_2d/mod.rs:84-90`). The effect-group/composite/main passes run **straight-line in the system body** under one shared `RenderContext` encoder (preserving the cross-pass `LoadOp::Load` composite ordering — separate systems would each get their own encoder and break it), exactly as the old single `ViewNode::run` did. `RenderContext` becomes a SystemParam; per-view data via `ViewQuery`. Update `node::register` to `add_systems(Core2d, buiy_pass.in_set(Core2dSystems::EarlyPostProcess))`. Pattern source: vendored `main_transparent_pass_2d`.
- T1.3b **GPU-test body rewrites** (not import swaps — these are real rewrites, but they only need to *compile* in Phase 1; behavior is re-verified in Phase 3). `tests/render_smoke.rs:75` (`render_graph_node_inserted_after_main_2d_pass`) asserts on `RenderGraph` topology (`get_sub_graph(Core2d).get_node_state(BuiyRenderLabel)`) — a premise that no longer exists; rewrite it to assert Buiy's pass system is registered in `Core2dSystems::EarlyPostProcess` with the right ordering. `tests/render_compositor_gpu.rs` drives passes via `RenderGraph` manually; rewrite to the systems model. Both are `#[ignore]` so they must compile under the Phase-1 `--all-targets` gate but their behavior gates on the Phase-3 GPU lane.
- T1.4 **wgpu compile-hard fields** (triage raw-`wgpu::` vs Bevy-wrapper first — grep `render/` for raw descriptor literals). Known raw sites: `RenderPassDescriptor.multiview_mask: None` (3 literals in `node.rs:163,247,280`); `SamplerDescriptor.mipmap_filter: MipmapFilterMode` (`atlas/gpu.rs:62`); raw `PipelineLayoutDescriptor` `immediate_size`/`Some(&bgl)` if any; `LoadOp` exhaustive-match arm if present.
- T1.5 **a11y + assets.** `TreeUpdate.tree_id: accesskit::TreeId::ROOT` (`a11y/translate.rs:80`). Verify `BuiyFontLoader::load` against the 0.19 `AssetLoader`/`Reader` signature (`Reader::seekable()` change) at `text/font_asset.rs:66-90`; verify `MessageReader<AssetEvent<…>>` naming at `registry.rs:330`. Verify the `ACCESS_KIT_ADAPTERS` re-export path/type survives in bevy_winit 0.19 (`a11y/adapter.rs`) — grep the vendored `bevy_winit/src/accessibility.rs`.

**Gate:** `cargo check --workspace` clean; `cargo clippy --workspace --all-targets -- -D warnings`; `cargo fmt --all -- --check`; `RUSTDOCFLAGS="-D warnings" cargo doc --workspace --no-deps`.

## Phase 3 — GPU lane green

On the GPU host (RX 6700 XT / lavapipe): `cargo test -p buiy_core -j 2 -- --ignored --test-threads=1`.

- T3.0 **R1 correctness gate.** The render-graph→systems rewrite (T1.3) compiled green in Phase 1 but its *paint correctness* (Buiy draws after main pass, before tonemapping; the three-pass effect-compositor nesting renders in the right order) is verified ONLY here. The existing golden/compositor GPU tests (`render_compositor_gpu.rs`, the effect-group goldens, `render_smoke.rs`) are the gate — a compile-green rewrite with wrong ordering fails here, not in Phase 1/2. Confirm goldens match pre-migration output (paint order unchanged).
- T3.1 The GPU-only wgpu churn surfaces here: `device.poll(PollType::…)` (`golden.rs:344`); `RenderQueue::write_texture` + `TexelCopyTextureInfo`/`TexelCopyBufferLayout` (`atlas/gpu.rs:112,127`); render-pass field sets; the rewritten pass systems actually drawing.
- T3.2 WGSL re-bless: run `tests/render_shader_wgsl.rs` under naga 29 (stricter const-eval/swizzle/`enable`/`@must_use`). Fix shader source if naga 29 rejects it. Re-bless shader/pixel goldens **only after confirming pixel-correctness**, never to silence a failure.

## Phase 4 — `buiy_bsn` crate + conformance

- T4.1 Create `crates/buiy_bsn` (add to workspace members): `prelude` re-exporting `bsn!`/`bsn_list!` + spawn ext traits (spec § 4.2). Thin; no new syntax. `bevy.workspace = true` inherits the `bevy_scene` feature additively (no feature edit).
- T4.1b **Wire `buiy_bsn` into the meta-crate** (spec § 4.2; fixes the B2 gap — without this `hello_bsn` cannot reach `bsn!`). Add `buiy_bsn = { path = "../buiy_bsn" }` to `crates/buiy/Cargo.toml`; in `crates/buiy/src/lib.rs` add `pub use buiy_bsn as bsn;` AND fold `buiy_bsn::prelude::*` into `buiy::prelude` so `use buiy::prelude::*;` brings `bsn!` into scope.
- T4.2 **Reflect-gap closure** (spec § 6, independent + small): `Display`/`FlexItem`/`LayoutAnchorBroken` reflect `Default`; `CaretColor` manual `Default` + reflect attr; register `FontStack`/`FamilyEntry`/`GenericFamily` in `BuiyTextPlugin`; `Angle`/`FilterFn` `Default` (parity).
- T4.3 **Widget `#[require]` adoption** (spec § 4.1a; the B1 fix — what makes `bsn! { Button }` usable). Add `#[require(...)]` to `Button` and `TextInput` markers in `buiy_widgets`, mapping the current `Button::new()` / `TextInput::single_line()` bundle contents into required-components with the widgets' canonical defaults as `#[require(C = init)]` initializers. Keep the existing constructors (back-compat; required-components no-op when the companion is explicitly present). TDD: a test that bare-`spawn(Button)` yields the full contract.
- T4.4 Component conformance audit: confirm every author-facing Buiy component is BSN-authorable via the `Clone+Default` blanket path (the decomposed style components already are); confirm `Style` (the `Bundle` builder) is correctly NOT authored via `bsn!` (decomposed components are); add `#[derive(FromTemplate)]` only where a component has context-bearing fields (none expected — flag any that does).
- T4.5 **Round-trip authorability test** (TDD — write first; spec § 5 required cases): spawn `bsn! { … }` trees against a `World` for (a) bare plain-data components with patches (`Background`, `BoxModel`, …); (b) a **styled widget** — `bsn! { Button { } Background(brand) BoxModel { … } }` asserting the `#[require]` contract materialized AND patches applied; (c) a `Children [ … ]`-nested subtree; (d) a `#Name` ref. Headless. Assert resulting entity components + patched field values.

**Gate:** `buiy_bsn` compiles; `buiy::prelude` exposes `bsn!`; widget `#[require]` test green; round-trip test (all 4 cases incl. styled widget) green headless; `cargo deny` still clean (new crate adds no new external dep beyond `bevy_scene`, already present).
